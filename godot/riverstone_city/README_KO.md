# 실행 가능한 Godot 도시 프로젝트

Godot 4.6.3 standard에서 이 폴더의 `project.godot`를 불러와 F6이 아니라 F5로 실행합니다. .NET과 Python은 플레이에 필요하지 않습니다. 엔진은 포함하지 않습니다.

명령행: `godot --path godot/riverstone_city`

WASD 이동, Shift 달리기, 마우스 오른쪽 버튼 및 방향키로 카메라, F8 사진. 도시 원본 좌표와 충돌을 유지하며 주변 타일을 읽습니다. 리소스가 없거나 지지면이 잘못되면 안전 정지합니다.

## 이 버전의 범위
기존에 배포해 플레이를 확인했던 기본 도시 + 원본 Lily r03 외형 안정본입니다. 최신 주택 near-detail, 다면 이미지 측정 복셀 실험, 3등신 후보를 모두 통합한 새 플레이 빌드가 아닙니다. NPC 행동과 경제 시스템은 포함하지 않습니다.

1,064개 필수 파일(208,829,042 bytes)을 독립 복사 후 검사했습니다. 1,061개는 원본과 동일하고 3개 JSON의 provenance 절대경로 및 관련 해시만 공개용으로 수정했습니다. 기하, 색, 충돌, 배치, 캐릭터는 바꾸지 않았습니다. 필수 타일 BIN/JSON과 native render JSON은 실행 자산이므로 추적합니다. `.godot`은 재생성 캐시라 제외합니다.

Godot 4.6.3 headless에서 실제 시작해 PLAYABLE_CITY_READY, exit 0, 초기 50개 타일과 106개 native 캐시 로드를 확인했습니다. 이는 전체 동선 재시험 또는 Windows/GPU 성능 측정이 아닙니다. 동적 리소스 1,024참조와 정적 preload는 해시/존재 검사 통과했습니다.

`RESOURCE_MANIFEST.json`으로 입력 및 공개본 SHA-256을 확인할 수 있습니다. 일부 원본 이미지 이름은 제작 이력으로만 남아 있으며 실행에 필요하지 않습니다. 사진은 포함하지 않습니다.
